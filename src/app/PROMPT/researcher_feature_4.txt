Prompt 4.3: Collaboration System (Request & Accept)
Create researcher collaboration system:

FEATURES:
- Send collaboration request to another researcher
- Include context/message with request
- View pending requests (sent and received)
- Accept/decline requests
- View active collaborations
- Collaboration list with filters
- Notification on new request

FLOW:
1. Researcher A finds Researcher B via search
2. Clicks "Request Collaboration"
3. Fills context form (research interest, proposal)
4. Request sent, Researcher B gets notification
5. Researcher B can accept/decline
6. If accepted, messaging chat opens

Please provide:
1. Collaboration requests page (app/dashboard/researcher/collaborations/page.tsx)
2. Collaboration components:
   - CollaborationRequestCard
   - RequestCollaborationDialog
   - AcceptDeclineButtons
   - CollaborationsList (tabs: pending/active/declined)
3. API routes:
   - GET /api/collaborations/requests
   - POST /api/collaborations/send
   - POST /api/collaborations/[id]/accept
   - POST /api/collaborations/[id]/decline
   - GET /api/collaborations/active
4. Notification service (lib/services/notifications.ts)
5. Real-time updates using WebSocket

Show status badges (pending/accepted) clearly.
