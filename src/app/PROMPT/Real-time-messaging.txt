Prompt 5.2: Real-Time Messaging Interface
Create real-time messaging system (only between researchers after collaboration accepted):

FEATURES:
- One-to-one chat interface
- Real-time message delivery
- Typing indicators
- Read receipts
- Message history (load more on scroll)
- Online/offline status
- File attachments (optional)
- Message timestamps
- Unread message counter

SECURITY:
- Verify collaboration status before allowing messages
- Only researchers can message
- Encrypted in transit

Please provide:
1. Messages page (app/messages/page.tsx)
2. Message components:
   - ConversationList (sidebar with contacts)
   - ChatWindow (main chat area)
   - MessageBubble (individual message)
   - MessageInput (with send button)
   - TypingIndicator
   - OnlineStatus
3. API routes:
   - GET /api/messages/conversations
   - GET /api/messages/[collaborationId]
   - POST /api/messages/send
   - PUT /api/messages/[id]/read
4. Message service (lib/services/messages.ts)
5. Socket event handlers for real-time updates
6. Infinite scroll for message history
7. Notification badge for unread messages

Style like modern chat apps (WhatsApp, Slack).
